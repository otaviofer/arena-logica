
## 👑 O Desafio: O Tesouro Real

Um rei quer saber quanto ouro ele tem no baú, mas ele tem uma mania estranha: ele só gosta de contar as moedas que são **múltiplas de 3** (ele diz que são moedas abençoadas).

**Sua missão é criar um programa que:**

1. Peça ao usuário um **valor inicial** (ex: 1) e um **valor final** (ex: 20).
2. Use um loop para percorrer todos os números desse intervalo.
3. Identifique quais números são múltiplos de 3 (Dica: `n % 3 === 0`).
4. Exiba na tela:
* A lista de todos os números múltiplos de 3 encontrados.
* Quantos números foram encontrados (**Contador**).
* A soma total desses números (**Acumulador**).



---

### 🛡️ Dicas para a missão (NPC Guia):

* **A Mochila (Variáveis):** Você vai precisar de três variáveis antes do loop: uma `string` para a lista, um `number` para a contagem e outro `number` para a soma.
* **O Filtro:** Dentro do `for`, use o `if` com o operador de resto (`%`) para decidir se aquele número entra ou não na contagem.
* **A Saída:** Tente exibir o resultado de uma forma organizada nas suas tags `h3`.
