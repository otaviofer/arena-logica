# Desafio: Simulador de Estratégia de Corrida 🏎️

Projeto prático para consolidar conhecimentos de **Estruturas Condicionais** em JavaScript/Node.js.

## 🧠 Conceitos Aplicados
- Operadores Lógicos (`&&`, `||`)
- Condicionais Compostas (`if`, `else if`, `else`)
- Seleção Múltipla (`switch case`)
- Entrada de dados via Node.js

## 🚀 Como executar
1. Clone o repositório
2. Execute `node index.js`
